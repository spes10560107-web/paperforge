## P13｜模型架構：MobileNetV3-Large 雙輸出頭（55 秒）

| 投影片內容 | 講稿 |
|-----------|------|
| **骨幹選擇理由：**<br>・輕量（5.4M 參數、219 MFLOPs）<br>・適合小樣本<br><br>**雙輸出頭：**<br>・分類頭：六等級分類<br>・品質分輔助頭：輸出 0–100 分<br><br>**三模型效率比較：**<br>MobileNetV3-Large：5.4M / 219M<br>EfficientNet-B0：5.3M / 390M<br>ResNet18：11.7M / 1.8G<br><br>品質分為排序輔助，非絕對量化 | 模型骨幹選擇 MobileNetV3-Large，原因是它夠輕量——只有 540 萬參數、219M FLOPs——且適合我們這種小樣本場景。相比之下，ResNet18 有 1,170 萬參數、1.8G FLOPs，計算量高出許多。<br><br>模型設計上採用雙輸出頭：分類頭負責六等級分類，品質分輔助頭額外輸出 0 到 100 分的連續品質分數。品質分的用途是排序輔助，而非絕對量化，提供比純分類更細緻的資訊。 |

| **Group Split（嚴格切分）：**<br>・原圖 ID 為群組，70/15/15 切分<br>・原圖零重疊，避免同源洩漏<br><br>**多 seed 重複：**<br>・種子值：7、42、123、1234、2024<br>・報告 mean ± std<br><br>**兩組策略對比：**<br>簡化：CE / 無 Mixup / 無過採樣 / ~24 步<br>完整：Focal+LS / Mixup α=0.3 / WeightedSampler / ~145 步（6 倍） | 為確保評估不受同源樣本污染，我們採用 Group Split——以原圖 ID 為群組進行 70/15/15 切分，讓同一原圖的裁切子圖不會同時出現在訓練集和測試集，避免資料洩漏。<br><br>另外以五個不同 seed 重複訓練，報告 mean ± std，提升結果的統計可信度。我們也比較了簡化設定與完整設定，完整設定每輪訓練步數約為簡化設定的 6 倍。 |

## P19｜五 seed 穩定性：主要結論（50 秒）

| 投影片內容 | 講稿 |
|-----------|------|
| MobileNetV3 簡化：81.19 ± 3.71% / F1 0.681 / QWK 0.921<br>MobileNetV3 完整：80.12 ± 5.98% / F1 0.713 / QWK 0.909<br>ResNet18 完整：80.83 ± 2.16% / F1 0.712 / QWK 0.914<br>EfficientNet-B0：81.19 ± 2.25% / F1 0.698 / QWK 0.910<br><br>①四組平均 accuracy 80.12%–81.19%，paired t-test **未達顯著差異**<br>②完整設定 std = 5.98%（最大）— **高方差為負面訊號**<br>③Bonferroni 校正後均不顯著 → **不宜稱任何設定為穩定最佳** | 跨五個 seed 的匯總結果顯示，四組模型的平均準確率介於 80.12% 至 81.19%，差距非常小。Paired t-test 結果未達顯著差異，表示統計上無法宣稱哪個設定最佳。<br><br>特別注意的是完整設定的標準差達 5.98%，是四組中最高的，顯示完整設定雖在單次表現較好，但穩定性反而不如簡化設定。Bonferroni 校正後所有比較均不顯著，因此我們不宜對任何設定做過度宣稱。 |
